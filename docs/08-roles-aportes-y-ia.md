# Roles, aportes y uso responsable de IA

## Integrantes y aportes

Completar con los datos reales del equipo. Todos deben poder explicar el producto completo, aunque hayan tenido una responsabilidad principal.

| Integrante | Responsabilidad principal | Aportes verificables | Evidencia |
|---|---|---|---|
| Completar | Coordinación / cliente | Completar | Commits, actas o tablero. |
| Completar | Interfaz | Completar | Commits, capturas o revisión. |
| Completar | Datos / backend | Completar | Commits, diagrama o pruebas. |
| Completar | Seguridad / pruebas | Completar | Matriz y correcciones. |

## Registro de uso de IA

La guía permite utilizar IA como apoyo, pero el equipo es responsable del código y debe comprenderlo. Registrar para cada uso:

| Fecha | Herramienta | Para qué se utilizó | Qué revisó/modificó el equipo |
|---|---|---|---|
| Completar | Completar | Investigación, alternativa, depuración o documentación. | Completar. |

## Compromiso para la defensa

Cada integrante debe poder explicar una funcionalidad, modificar un fragmento, justificar una decisión y describir una dificultad real. La existencia de código generado o sugerido por IA no reemplaza la comprensión del equipo.
